#### Сценарий A1: Попытка регистрации с существующим именем

1. Перейти на страницу регистрации
2. Ввести имя пользователя "existing_user"
3. Ввести пароль и подтверждение
4. Нажать "Зарегистрироваться"

#### Сценарий A2: Попытка добавить отзыв без авторизации

1. Открыть детальную страницу игры
2. Нажать кнопку "Войдите, чтобы оставить отзыв"
3. После входа происходит редирект обратно на страницу игры

#### Сценарий A3: Попытка добавить второй отзыв на ту же игру

1. Открыть детальную страницу игры с существующим отзывом
2. Нажать кнопку "Оставить отзыв"
3. Нажать "Редактировать отзыв"

#### Сценарий A4: Попытка добавить в избранное без авторизации

1. Открыть детальную страницу игры
2. Попытаться перейти по прямому URL /add-to-favourite/1/
