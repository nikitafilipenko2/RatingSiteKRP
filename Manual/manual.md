**1. Регистрация и вход в систему**

Регистрация нового пользователя:
На главной странице нажмите ссылку "Регистрация" в правой части навигационной панели
Заполните форму:
Имя пользователя - придумайте уникальное имя
Пароль - не менее 8 символов
Подтверждение пароля - введите пароль еще раз
Нажмите кнопку "Зарегистрироваться"
После успешной регистрации вы будете перенаправлены на страницу входа
Вход в систему:
Нажмите ссылку "Войти" в навигационной панели
Введите имя пользователя и пароль
Нажмите "Войти"
После успешного входа в навигации отобразится ваше имя пользователя
Выход из системы:
Нажмите кнопку "Выйти" рядом с вашим именем в навигационной панели

**2. Управление профилем**

Просмотр профиля:
Нажмите "Мой профиль" в навигационной панели
На странице профиля отображаются:
1. Аватар пользователя
2. Имя пользователя
3. Статистика (отзывы, избранное, оцененные игры)
4. Информация "О себе"
5. Контактные данные
6. Последние отзывы
7. Последние избранные игры

Редактирование профиля:
На странице профиля нажмите кнопку "Редактировать профиль"
В открывшейся форме вы можете изменить:
1. Аватар - загрузите изображение (рекомендуемый размер 300x300px)
2. Имя пользователя - при необходимости
3. Email - укажите контактный email
4. Имя и фамилию - для персонализации
5. О себе - краткая информация о вас
6. Дату рождения
7. Местоположение
8. Веб-сайт
9. Telegram - в формате @username
10. Discord - в формате username#0000
После заполнения нажмите "Сохранить изменения"

**3. Работа с каталогом игр**

* Просмотр списка игр:
* На главной странице отображается список игр с пагинацией (10 игр на страницу)
* Каждая карточка игры содержит: название, жанр, год, разработчика, издателя, рейтинг и количество в избранном
* Поиск и фильтрация:
* В левой части главной страницы находится панель фильтров

1. Поиск - введите текст для поиска по названию, разработчику или издателю
2. Жанр - выберите конкретный жанр из выпадающего списка
3. Разработчик - выберите конкретного разработчика

Сортировка - выберите порядок отображения:

1. По названию
2. По рейтингу
3. По популярности (количество в избранном)
4. По отзывам
5. Новые сначала
6. Старые сначала

* Нажмите "Применить" для применения фильтров
* Для сброса всех фильтров нажмите "Сбросить фильтры"
* Детальная страница игры:
* Нажмите на карточку игры или кнопку "Подробнее"
* На странице отображаются:
* Полная информация об игре
* Статистика оценок (средний рейтинг, количество оценок, количество в избранном)
* Список отзывов пользователей

**4. Работа с избранным**

* Добавление игры в избранное:
* На детальной странице игры нажмите кнопку "В избранное" (красная)
* Кнопка изменится на "Удалить из избранного"
* Появится сообщение об успешном добавлении
* Просмотр избранного:
* Нажмите "Избранное" в навигационной панели
* Отображается список всех добавленных игр с датой добавления
* Удаление из избранного:
* На странице избранного нажмите кнопку "Удалить" на карточке игры
* Подтвердите удаление в диалоговом окне
* Игра исчезнет из списка
* Альтернативный способ: на детальной странице игры нажмите кнопку "Удалить из избранного"

**5. Работа с отзывами**

* Создание отзыва:
* На детальной странице игры нажмите кнопку "Оставить отзыв" (зеленая)
* В открывшейся форме:
* Выберите оценку от 0 до 10 (обязательно)
* Напишите текстовый комментарий (опционально)
* Нажмите "Опубликовать отзыв"
* Отзыв появится в списке отзывов
* Редактирование отзыва:
* Найдите свой отзыв в списке
* Нажмите иконку редактирования (✎) рядом с оценкой
* Внесите изменения в форму
* Нажмите "Сохранить изменения"
* Удаление отзыва:
* Найдите свой отзыв в списке
* Нажмите иконку удаления (×) рядом с оценкой
* Подтвердите удаление
* Отзыв исчезнет из списка

**6. Рекомендации**

* Персональные рекомендации:
* После добавления нескольких игр в избранное на главной странице появится блок "Рекомендуем для вас"
* Рекомендации основаны на жанрах и разработчиках игр из вашего избранного
* Чем больше игр в избранном, тем точнее рекомендации
* Популярные игры:
* На главной странице отображается блок "Популярные игры"
* Популярность рассчитывается на основе количества добавлений в избранное и оценок
